🎬 MovieIQ — Movie Success Prediction

An end-to-end machine learning project that predicts whether a movie is likely to be successful based on Budget, Popularity, Runtime and Vote Average.

The project covers the complete analytics workflow: data preparation, exploratory data analysis, statistical testing, class imbalance handling, Balanced Random Forest modeling, evaluation and Streamlit deployment.

Python Pandas Scikit-learn Machine Learning Balanced Random Forest Streamlit Statistics

Success Definition: A movie is classified as successful when its revenue is greater than its production budget.

Key Work:

  • Performed Exploratory Data Analysis on movie data.
  • Created the movie success target based on revenue versus budget.
  • Analyzed relationships between budget, popularity, runtime, ratings and movie success.
  • Performed statistical testing using T-Test and Chi-Square Test.
  • Addressed class imbalance using a Balanced Random Forest approach.
  • Built and evaluated the machine learning model.
  • Developed an interactive Streamlit application for real-time movie success prediction.
